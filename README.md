# Video Calling Website

## Overview
Welcome to **BZoom**, a video calling platform where you can effortlessly start and join video conferences. The project is currently 60% complete, but the core functionality is fully operational.

## Features (Completed)
- User authentication system.
- Ability to create and join video calls.
- URL sharing for easy meeting access.
- share screen functionality
- react emoji
- record call (not storing)

## Features (In Progress)
- Enhanced UI/UX for the video call interface.
- Additional meeting management features (e.g., scheduling, participant controls).
- Chat integration.

## Getting Started
Follow these steps to use the website:

1. **Visit the Website**: Navigate to [bzoom.vercel.app](https://bzoom.vercel.app).
2. **Login**: Use your credentials to log in.
3. **Start a New Meeting**:
   - On the home page, click the **New Meeting** button.
   - Start the meeting and copy the generated URL.
4. **Join the Meeting**:
   - Paste the URL into a new tab to join the conference call.

## Notes
- Ensure your device has a functional camera and microphone for the best experience.
- Supported browsers: Chrome, Edge, and Firefox (latest versions).
